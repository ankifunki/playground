# Old site archive (joshiankit.com, 2017)

Text and original images from the eight case studies on the WordPress site, saved on 15 Oct 2026 as raw material for the new portfolio.

The live site has an injected script on every public page that loads HTML from `portal-secure.app` (a fake-CAPTCHA malware pattern). This archive was made from static HTML only. No page scripts were run, the raw HTML was not kept, and every downloaded file was checked: all are real PNG, JPEG, GIF or SVG images, and none of the SVGs contain scripts or event handlers.
