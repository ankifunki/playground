04 Key decision

A location switcher in each workflow.

Global

One switcher for the whole app. No central view for owners.

Chosen

Per workflow

"Team at Soho". Works for owners and operators, at any number of locations.

Hybrid

Both. Two switchers with conflicting logic.

05 System

Five patterns, every surface.

Default, then override

Set once for the business, customize per location or person.

Assign to locations

Staff, services and clients belong to one or more locations.

[Surface] at [Location]

A filter in each workflow, with "All locations" for owners.

Bulk by default

Invite, assign and update many at once.

Built for 20+

Pickers search and truncate at scale.
